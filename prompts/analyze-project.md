# Analyze a configured project

Use `$career-analyze-project` for `<project-id>`.

Read the latest private scan, the configured project context, existing drafts, and existing initiatives. Inspect the project directly through the directory already granted to Codex.

Identify meaningful workstreams and create or update private drafts only. Be conservative about attribution and mark all unsupported outcomes as needing confirmation. Do not create public copy and do not modify `content/public/`.
