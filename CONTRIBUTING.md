# Contributing

Career Ledger is optimized for a single owner, but contributions are welcome.

Before opening a pull request:

```bash
npm run check
```

Public-content changes must satisfy the privacy and approval rules in `AGENTS.md` and `content/public/AGENTS.md`.

Do not include real private repository paths, client names, internal ticket IDs, secrets, commit hashes, or raw work evidence in issues, pull requests, fixtures, screenshots, or examples.

For behavior changes, include tests and update the relevant document under `docs/`.
